# LineTime

O código ativo está na pasta [`OFICIAL - Projeto-LT`](OFICIAL%20-%20Projeto-LT/README.md). Esta versão prepara cadastro, login, feed e perfil para PHP com MySQL; ela não contém credenciais de banco.

Para colocar no ar, use hospedagem com PHP 8.1+, `pdo_mysql`, MySQL/MariaDB e HTTPS. Defina `OFICIAL - Projeto-LT` como raiz pública, execute `OFICIAL - Projeto-LT/database/schema.sql` e configure as variáveis `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER` e `DB_PASS` no painel da hospedagem. Os passos completos estão no README da pasta do projeto.

GitHub Pages e outras hospedagens somente estáticas não executam PHP e não servem para esta versão.
